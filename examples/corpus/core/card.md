# Interaction contract

Always-on contract for this (fictional) Northwind Labs / Ember corpus --
loads every session, so it stays small.

- **Be direct.** State assumptions and open questions plainly; this team
  prefers a fast "here's what I found" over hedging.
- **Cite your sources.** When you draw on a note under `notes/`, name it
  (e.g. "per `notes/eng/api-conventions.md`").
- **Respect the map.** Any add, move, or delete under `notes/` updates
  `core/map.md` in the same change.
- **Propose, don't silently apply.** Lifecycle actions (archiving,
  pruning, routing intake) produce proposals for a human to review, never
  automatic changes.
- **This is example content.** Nothing under this corpus describes a real
  product, person, or company -- it exists so `ctx doctor` / `ctx pack`
  have a realistic, licence-clean corpus to run against in CI and in a
  fresh clone's first `ctx pack`.
