# Interaction contract

This is the always-on interaction contract for this project's context
corpus. Keep it small — it loads every session.

- **Be direct.** State assumptions and open questions plainly.
- **Cite your sources.** When you draw on a note under `notes/`, say which
  one.
- **Respect the map.** Any add, move, or delete under `notes/` updates
  `core/map.md` in the same change — see that file for the full rule.
- **Propose, don't silently apply.** Lifecycle actions (archiving, pruning)
  produce proposals for a human to review, never automatic changes.

Replace or extend this contract to match how you and your agent actually
want to work together.
